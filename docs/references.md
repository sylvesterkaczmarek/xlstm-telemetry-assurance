# References

The recurrent mechanism is motivated by the xLSTM family rather than presented as an independent invention.

1. Beck, M. et al. (2024). **xLSTM: Extended Long Short-Term Memory**. arXiv:2405.04517. https://arxiv.org/abs/2405.04517
2. xLSTMTime authors (2024). **xLSTMTime: A Competitive Recurrent Architecture for Long-Term Time Series Forecasting**. arXiv:2407.10240. https://arxiv.org/abs/2407.10240

The repository uses a compact stabilized exponential-gating recurrence suited to an inspectable benchmark. It does not reproduce the complete official xLSTM implementation or claim equivalence to every xLSTMTime architectural choice.

For PyTorch implementation details, see the official PyTorch documentation: https://pytorch.org/docs/stable/
